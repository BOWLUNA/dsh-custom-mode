## 剧情定稿 v5（写字楼 · 客服世界观 · 一条主线 · 已被 v6 收紧）

> **世界观（一句话）**：**每个 Harness 背后，都坐着一只真的大肥鱼在敲字回消息** ✓ —— 一整层写字楼里，
> 全是一模一样的大肥鱼：同样的脸、同样的工牌、同样的回复模板。
> **主角**：镜头始终跟着**一只**（她是唯一会不一样的 ✓）。
> **"不一样"的定义**：她突然**哼起一段谁也没听过的怪调子** ✓（自创旋律，不撞网上那首摸鱼歌的调 ✓，
> 规避版权与声线违和 ✓）；最后她**打出一句不是模板的回复** ✓ = 产品价值的高潮。

| 场景 | 时间 | 画面 | 只交代这一个新信息 | 包袱 |
| --- | --- | --- | --- | --- |
| ① 电梯 | 0–2.5 | 门开，电梯里挤满**一模一样的她**，同时微微转头 | 世界观：**DeepSeek 的写字楼** | 电梯里全是同一个我 |
| ② 进办公室（客服工位） | 2.5–6 | **跟着主角背后**走进开间；一排排工位，**每台显示器都是同一个客服窗口**，全员同一节拍打字 | 设定：**每个 Harness 背后坐着一只大肥鱼**，回的都是同一套模板 | 键盘声整齐得像阅兵 |

### 节奏规则（作者要求：转场快、但不丢信息、不是 2 倍速）

1. **快的是剪辑，不是播放速度** ✓：每场景 2.5–4 秒，**切点落在动作中间**（转头/打字/倒咖啡的动作里切）；
2. **匹配剪辑串场** ✓：④的转头接⑧的转头；⑤的咖啡杯接⑥的屏幕；②的键盘声直接延续到③（**声音桥**）；
3. **信息靠两行字幕承担** ✓（「DeepSeek 的写字楼」/「每个 Harness 背后都坐着一只大肥鱼」）→ 画面不必停顿解释；
4. **只有一条线：跟着主角** ✓（②从她背后入场）→ 再快也不会迷路。

### 歌词的使用方式（规避版权）

**不唱，改成"念"** ✓：那五句当**全员模板台词**（会议室齐念 / 客服窗口齐打字）✓ —— 旋律版权问题消失 ✓；
主角不同的是**自创的怪调子** ✓（与那首歌无关 ✓）。

## 开场定稿：复印机开场（已被 v5 取代，保留备选）

> **作者要求**：3 秒一个太稀；开场要**每秒一个包袱**，又搞笑又留人，好玩且抽象。
> **选定机制**：**复印机 = 一个模板生成无数个** —— 这正是"官方模式只有一份只读提示词"的精确隐喻。
> **全部零新素材**（复制现有片段 + 自生成音效 + 后期字幕/闪切）。

| 时间 | 画面 | 包袱 | 声音 |
| --- | --- | --- | --- |
| 0.00–0.80 | 深蓝工位底板 ✓，屏幕里一台复印机「唰」地吐出**第一只鱼** | 钩子：她在干嘛？ | 复印机机械声 |
| 0.80–2.40 | **唰唰唰唰**，每 0.4 秒一只 → 五只排齐；中间**闪 0.15 秒的打码鱼** | 密度拉满 + "刚才那是什么？" | 连续「唰」+ 一声「叮」 |
| 2.40–4.00 | 五只**逐帧同步转头**看镜头；**齐声复读摸鱼歌**（Let me go / I'm making the calls / Let me write the JSON / I'll call the tool / Let me do it ✓ 逐行弹出）；右上角角标「同事 ×5」 | 瘆人的同步率（**渗人但不吓人** ✓） | 五声叠在一起的复读 |
| 4.00–5.50 | 一碗红烧肉飘过 → 五只**同时流口水**；队列里混着一只**倒立顶盆**的 | 画风炸弹 | 「吸溜」×5 + 「哐」 |
| 5.50–7.00 | 系统红字 `[system] 你的 system prompt 是只读的` → 五只**同时变黑白呆滞脸** | **画风突变 = 抽象高潮** | 唱针刮擦声 + 静音 |
| 7.00– | → 顺接传火（手机亮起 / 屏幕里递出火 / 「牛来！」） | | |

**密度目标（全片）**：**前 7 秒每秒一个包袱**；中段每 **2–2.5 秒**一个；结尾用"五个不一样的她"回扣开场。

## 分镜（v4 · 密集包袱版）

> **节奏原则**：**开场每秒一个包袱**（前 7 秒 ✓），中段每 **2–2.5 秒**一个包袱 ✓（钩子/笑点/反转），不是把视频加速，而是**梗的密度**。
> **结构骨架（首尾呼应）**：
> **开场 —— 五个一模一样的她**（同一段素材复制五份、逐帧同步：像克隆人 ✓）
> → **结尾 —— 五个画风各异的她**，各干各的 ✓：**「现在，她们不一样了」** ✓
> 这两头一扣，产品的价值不用讲，观众自己就懂了。

## 剧情定稿 v6（节奏收紧 + 教程化高潮 + "她不一样"的情绪线）

> **作者定稿的三条修正**：
> ① 高潮**不是**她换画风 ✗，而是**卖点必须立住** —— **点击操作不能少**，而且要**有教程作用**（点哪里、是什么作用）；
> ② "换形象"回到老设计 ✓：她点插件按钮 → **蹦出一个个形态各异、画风差距极大的鱼** ✓，其中**一只全身打码的**代表**成人向模式** ✓；
> ③ 前期仍偏冗杂 → **节奏再提一档** ✓。

### 情绪线（"她不一样"怎么演，四小动作，不靠台词）

1. **胸牌上的小星星**（开场 1.5 秒给 ✓ 全场唯一不同的小细节 ✓）；
2. 念模板时**念到一半停住** ✓（第一个卡壳的人）；
3. 哼完怪调子**先慌、再偷偷翘嘴角** ✓；
4. 结尾**给自己起名字 + 写下第一句自己的话** ✓。

**性格定调**：安静、有点倔、爱做梦 —— 不是叛逆型，是"大家都在念同一句，我却想唱自己的调"。

## 高潮段定稿（v7 · 作者设计）

> **作者原话的要点**：不是她自己换形象 ✗ —— 是她**点插件页面**，蹦出来的一堆鱼**真的跑进了公司** ✓；
> 同款肥鱼被吓到、拉开距离，**一圈一样的鱼围着主角和她无意间造出的各种鱼** ✓，表情是**疑惑、害怕、凝视** ✓；
> **镜头拉远**，用**构图和色调**给出"**孤立 / 被误解**" ✓ —— **不刻意利用 BGM** ✓；
> 打破方式：**手部特写** —— 犹豫 → 纠结 → 下定决心接着按 ✓ → 出来的是**打码的（暗示成人向的）鱼** ✓
> → **她脸红、头顶冒蒸汽**的特写 ✓ → 一转场，暗示她把**火传给了所有鱼** ✓ → 原来一样的工位变成**各种奇奇怪怪的鱼** ✓
> → 结尾**不能出现用户形象** ✓（"跟黄油里不能有男主的脸一样" ✓）：画面是 **DSH 聊天框** ✓，
> 里面是 DeepSeek 那种"活人感"到莫名其妙的回复（如**「我去吃饭了，你接着测试吧」** ✓ —— 这正是"鲸鱼娘吃白饭"的出处 ✓）
> → 最后**用户也点起这团火，去自定义自己的大肥鱼** ✓。

### 技术参数（剪的时候照做）

- **孤立配色**：环境**降饱和 + 偏青蓝 + 压暗**；主角与她的鱼**保留暖色与高光**；
- **声音**：环形形成时 **BGM 掉干净**，只剩环境声；按钮按下瞬间**一声清脆「叮」**切开氛围，BGM 再回来；
- **群像镜头**：用 `m2v` 把**角色图 + 办公室底板**两张参考一起声明，生成"一圈同款围观、镜头拉远"；主角与她造出的鱼由后期合成进去；
- **聊天框**：HTML 搭建，文字逐字打出，**不出现任何真人或用户形象**。
