# 剧本 · 定稿

**片名**《她不一样》 ｜ **片长** 42 秒（另出 ~30 秒精简版） ｜ **画幅** 1920×1080 ｜ **帧率** 24fps
**镜头级细节（38 个镜头的景别/机位/时长/声音/素材）见 `导演文件/02-分镜表.md`** —— 本文只讲**故事与规范**，不重复镜头表。

---

## 1. 一句话与主题

**每个 Harness 背后，都坐着一只真的大肥鱼在敲字回消息。** 一整层写字楼里全是一模一样的她 ——
同样的脸、同样的工牌、同样的模板回复。直到有一天，**有一只哼出了不一样的调子**。

- **剧情层**：一个"想要不一样"的小人物，在一屋子复读机同事里，先被围观、被误解，最后**给自己争来一个自己的声音**。
- **产品层**：那个声音就是**可编辑的 system prompt**；她的争法就是**装上 dsh-custom-mode 并点开它的设置页** ——
  卖点全部长在"她的自救"动作里，**不插播广告**。

## 2. 世界观与人物

| 项 | 设定 |
| --- | --- |
| 世界 | 一层普通的 DeepSeek 写字楼：电梯、开间办公区、会议室、茶水间、她的工位 |
| 她们的职业 | **客服** —— 工位上的显示器就是真实 DSH 的客服窗口 / 设置页（**真界面 = 她屏幕上的画面**） |
| 主角 | 五只同款里**唯一会不一样**的一只；胸牌上贴着一颗**小星星**（全片唯一不同的细节） |
| 性格 | 安静、有点倔、爱做梦 —— 不是叛逆型，是"大家都在念同一句，我却想唱自己的调" |
| 她的"台词" | **全片只有一句**：那段**自创怪调子**（哼唱，短，不成曲，不撞网上那首歌的调） |
| 超自然设定 | **只有两个**：那团**火（prompt.md）**，和"**屏幕是门**"。其余一切物理可信 |

## 3. 四幕结构（42 秒）

| 幕 | 时间 | 内容 | 情绪 |
| --- | --- | --- | --- |
| **一 · 一样** | 0–9s | 电梯 → 办公区 → 会议室复读；红烧肉五碗同流口水；**她念到一半停住、哼出怪调子** → 全员转头 | 荒诞 → 心动 |
| **二 · 火** | 9–18s | 茶水间（同一杯咖啡）；屏幕红字"只读"；**屏幕里递出火**（「牛来！」）；**教程段：四次真实点击** | 转机 |
| **三 · 炸开与孤立** | 18–31s | 点【新增助手】→ 鱼从屏幕里掉出来、跑进办公室；同款瑟缩、椅子后退；**一圈凝视的长镜头**；三张脸特写（疑惑/害怕/凝视）；**她的手指：犹豫 → 纠结 → 按下** | 压力 → 憋住 |
| **四 · 释放与扩散** | 31–42s | 蹦出**打码的（成人向）鱼** → 全场静默 → **她脸红冒蒸汽**；火光扫过 → 工位变成各种奇奇怪怪的鱼；**DSH 聊天框结尾**（无用户形象）→ 用户也点起火 | 释放 → 温暖 → 莞尔 |

## 4. 台词与字幕（全集）

**她说出口的只有**：那段怪调子（无字幕）。

**她的五句"模板台词"**（会议室齐念 / 客服窗口齐打字，**念白，无旋律**）：
```
Let me go. / I'm making the calls. / Let me write the JSON. / I'll call the tool. / Let me do it.
```

**全片字幕**（按顺序）：
「DeepSeek 的写字楼」→「每个 Harness 背后，都坐着一只大肥鱼」→「连说话都是模板」→「对同一个东西，反应也一样」→
「**她不一样**」→「你的 system prompt 是只读的」→「改名：只影响显示」→「换底子：这个模式装哪些能力」→
「逐行开关：这一行管什么」→「想做几个助手都行」→「成人向模式」→「……又多了一个」→
「**现在，她们不一样了**」→ AI「我去吃饭了，你接着测试吧」→ 用户「？」→「**下集：她把火烧给了别人**」

## 5. 笑点与梗清单（每个梗的落点）

| 梗 | 落点 |
| --- | --- |
| **五只一样的她**（克隆感） | 开场 0–9s：同一段素材复制五份、逐帧同步（真复制比画的更瘆人也更好笑） |
| 五句复读台词 | 会议室齐念 + 客服窗口齐打字（**念，不唱**，规避旋律版权） |
| 红烧肉 | 会议室五碗 → 五只同时流口水；背景彩蛋：**红烧肉自动贩卖机** |
| **打码鱼**（暗示成人向） | 蹦鱼时的一只 → 字幕「成人向模式」；全片静默 0.5 秒的落点 |
| **顶盆鱼** | 蹦鱼时的一只 + 背景彩蛋（某工位趴着一只头扣铁盆睡着的鱼）；三视图已备好 |
| **大笑奶龙** | 她第一次成功"不一样"之后的憨笑（**夸张卡通，不吓人**） |
| **牛来** | 安装成功那一下的确认音（向社区 `dsh-niulai-sound` 插件致敬） |
| 吃白饭 | 结尾聊天框：AI「我去吃饭了，你接着测试吧」 |
| 画风炸开 | 水彩 / 黑白漫画 / 贴纸 / 3D 玩具奶鲸 / 真盆拼贴 / 像素 / 蒸汽波…… **同框即笑点** |

## 6. 情绪线与表演提示

| 阶段 | 外化动作（不靠台词） | 她想表达 |
| --- | --- | --- |
| 第一幕 | 缩在角落 · 叹气 · 念到一半**嘴停在半张** · 悄悄翘嘴角 | 我已经习惯一样了，但我不甘心 |
| 第二幕 | 低头看咖啡 · 接住火时**手一顿** | 也许这就是个机会 |
| 第三幕 | 环视一圈 · **喉咙动一下** · 握紧火 · **指尖轻颤 → 指节发白 → 按下** | 我不想再一样了 |
| 第四幕 | 脸红冒蒸汽 · 憨笑 · 把火**递出去** | 原来"不一样"是可以给的 |

## 7. 节奏规则（前紧后松）

1. **快的是剪辑，不是倍速**：第一幕每镜 1.2–1.8 秒，切点落在**动作中间**，4 秒走完三场；
2. **声音桥**：上一场的键盘声延续到下一场；
3. **信息靠字幕**：两句世界观字幕钉死设定，画面不必停顿解释；
4. **只有一条线**：镜头始终跟着主角；
5. **后段慢下来**：第三幕后段每镜 1.5–3 秒，**每个慢拍只揭示一个新细节**；
6. **不要在"点"上切**：打码鱼出来后多停 0.5 秒，让那一拍落地。

## 8. 语气安全线

**渗人 ≠ 吓人**：可以诡异、抽象、荒诞，但**绝不做恐怖向** ——
卡通化夸张、喜剧向；不出现恐怖意象、空洞眼窝、血、扭曲肢体、真实惊吓。
（平台对"真吓人"判定很严，而且我们的受众是来看"可爱 × 抽象"的。）

## 9. 视觉总纲

1. **一个场景**：全片只发生在写字楼这一层，不换场；
2. **背景统一、角色随便炸**：背景永远是同一间真实质感的办公室；角色画风随意（**真实场景 × 平面角色的拼贴反差就是喜剧底色**）；
3. **真界面 = 她屏幕上的画面**（diegetic）：切到真录屏时用**过肩镜头**推进，不要硬切；
4. **尺寸可夸张**：小到巴掌大、大到塞满整屏（奶鲸）；
5. 角色入场必须带**接触阴影 / 环境色**，否则会"飘"在场景外。

## 10. 真实 UI 融入规范（硬规范）

1. **屏幕要有物理痕迹**：显示器边框、反光、扫描线、她屏幕在房间里的冷光 ——
   真页面是深色的 → 办公室保持冷调 → **她的屏幕是房间唯一暖光源**；
2. **动作与页面反应同帧**：她按下的那一帧，页面里对应开关同时翻动（CDP 同帧真实点击，**不是后期对拍**）；
   **关掉一行 → 房间里对应东西暗一下**（UI 影响物理世界）；
3. **屏幕是"门"**：点【新增助手】→ 屏幕表面涟漪 → 鱼从屏幕里掉到桌上再跑进办公室；
4. **音频室内化**：屏幕里的声音**略微滤波**（像从显示器里传出来）；
5. **反向镜头**：从屏幕里往外拍（画面边缘是显示器边框）→ 外面站着一圈同款（孤立感 + 真实 UI 视角，一箭双雕）；
6. **教程作用**：每次点击都给控件特写 + 字幕标明"点哪里、什么作用"。

## 11. 形象与场景生成铁律

1. **场景单独生成**（空底板，不带角色）；**角色图不带场景**（干净背景，纯绿 / 纯洋红，**别用纯白** —— 她的白围裙会被抠掉）；
2. **出视频时把角色 + 场景两张参考一起声明**（`m2v` 多参考）；
3. **身份用文字写死、风格用关键词指定**；参考图只用于"该风格本来就有参考"的那几种；
4. **绝不拿萌萌鱼 2D 三视图当风格参考** ✗（i2i 会锁死画风，这是翻车的根因）；
5. 角色图**三视图优先**（正/侧/背都能用，也方便做转身）。
