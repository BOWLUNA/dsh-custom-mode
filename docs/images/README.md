# 截图清单

把截图放到本目录，文件名按下表。README 会引用这些名字，**文件名一致就不用改文档**。

## 需要哪几张

| 文件名 | 内容 | 说明 |
| --- | --- | --- |
| `01-mode-switch.png` | 设置 →「自定义模式」上半部分：**模式名称** + **基础模式**四个卡片 | 最重要的一张，放 README 最上面。最好能看到选中项的高亮描边 |
| `02-plugin-switches.png` | 中间部分：**插件开关**列表，含一个分组（如「委派与工作流」）和它的子行 | 体现「一行一个开关」和分组的缩进关系 |
| `03-system-prompt.png` | 下半部分：**系统提示词**文本框 + 底部保存栏 | 体现「保存即生效」 |
| `04-preset-picker.png` | 新建会话时的**模式选择器**，能看到「自定义模式」这一项 | 证明它真的作为一个模式存在 |
| `05-dark.png` | 与 `01` 同画面，但**深色模式** | 证明深浅色都适配 |
| `06-english.png` | 与 `01` 同画面，但**界面语言切成 English** | 证明双语 |

## 拍摄建议

- **窗口别太窄**：卡片是双列的，面板宽度足够才好看；窄了会自动降单列（那是刻意做的自适应，但不适合当封面图）。
- **一张图只讲一件事**：`01` 别把下面几百行开关都拍进去，太长在 GitHub 上会缩得很小。
- **可选**：如果想更直观，`03` 之后补一张「改完提示词 → 新会话里 agent 复述出新内容」的对话截图，这是最有说服力的功能证明。

## 放好之后

在仓库根目录执行：

```sh
git add docs/images
git commit -m "docs: 加入界面截图"
git push
```

然后在 README 里引用（我可以帮你插进合适的位置，把图发我或直接说一声即可）：

