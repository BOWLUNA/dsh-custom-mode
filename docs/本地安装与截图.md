# 在你的电脑上装一份（用于截图和后续开发）

## 前提

```sh
dsh --version     # 应该是 0.1.6-alpha.1 这一代
git --version     # 需要 git
```

> **版本不一致就告诉我。** 本项目深度依赖 DSH 内部 API，README 里的「耦合点清单」列了 11 个可能断裂点。如果官方已经发新版，我需要先核对再让你装。

## 安装

```sh
git clone https://github.com/BOWLUNA/dsh-custom-mode
cd dsh-custom-mode
./install.sh
```

`install.sh` 做了两件事：

1. 把 `preset/` 复制到 `~/.dsh/.agent-presets/custom/`（agent preset 是**目录**，不是 npm 包）；
2. 用 `dsh plugin --profile web add ./editor` 把设置页插件装进 profile。

装完**重启 dsh**（浏览器半只在启动装配期被发现）。

- 换 profile：`./install.sh --profile tui`
- 卸载：`./uninstall.sh`（默认保留你写的提示词；`--purge` 一起删）

## 改代码后的调试循环（重要）

**改 `editor/client.js` 不需要重启，也不用刷新页面**：`dsh-client-hmr` 会轮询 bundle 文件，约 1 秒后把插件原地换掉。

只有改**宿主半**（`index.mjs`、`composition.mjs`、`meta.mjs`、`paths.mjs`）才需要重启 dsh。

## 跑测试

```sh
# 从源码 checkout 跑时，出厂预设不在仓库里，需要指路
DSH_SHIPPED_PRESETS_DIR="$(dirname "$(find ~/.dsh -name 'dsh-agent-presets' -maxdepth 6 -type d 2>/dev/null | head -1)")/presets" \
  node test/composition.test.mjs

node test/locales.test.mjs
```

（装进 profile 之后，`editor/composition.mjs` 能自己定位出厂预设，就不需要这个环境变量了。）
